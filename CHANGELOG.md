# Changelog

## 1.1.0

- In-game text in every language the game supports: German, Spanish, French, Italian, Japanese, Korean, Polish, Brazilian Portuguese and Russian, besides English and Chinese.
- The Brazilian Portuguese language name now shows correctly in the conversion prompt.

## 1.0.0 (pre-release)

First public release.

- Adds **Convert a copy** to the warning shown when a save was started in another language.
- The copy's item names, descriptions, customers, factions, news, night logs and notes are switched to the current language using the game's own string tables. The original save is never modified.
